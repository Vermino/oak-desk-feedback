# Oak Desk: bug reports and ideas

Oak Desk is a desk for people who manage AI agents. When an agent like Claude Code or Codex needs a decision it
shouldn't make alone, it posts a card to the desk. The card shows up on your desktop and your phone, you answer in a
tap, and the agent carries on.

Oak Desk is in **closed beta** and free to use. Its source code isn't public. This repository is where you report
bugs, ask questions and suggest ideas.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml). Please include your Oak Desk version, where the server
runs (this computer, a homelab or NAS, Docker), and what you expected to happen.

Don't paste tokens, pairing codes or private data from your rounds into an issue. Issues here are public.

## Suggest an idea

[Suggest an idea](../../issues/new?template=idea.yml). Say what you were trying to do; that helps more than a
proposed solution.
